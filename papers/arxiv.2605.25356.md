Title: Names Are All You Need: Effective and Safe Regression Test Selection for Python

TL;DR: Fine-grained name-dependency regression test selection for Python; skips 69.90% tests while selecting affected tests for 99.6% commits

Brief Summary: First fine-grained Python regression-test selection approach based on code-element/name dependency reachability rather than unsafe call graphs or over-conservative file dependencies.

Key Result: Skips 69.90% of test files on average, cuts end-to-end test time by 45.59%, and selects all affected tests for 99.6% of commits.
