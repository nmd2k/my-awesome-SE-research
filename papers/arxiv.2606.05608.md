Title: Agentic Software: How AI Agents Are Restructuring the Software Paradigm

TL;DR: Formalizes distinction between traditional deterministic software (code carries pre-written decision logic) vs agentic software (agent itself is software, decision logic generated at runtime); traces SaaS → Agent-as-a-Service shift; introduces Agentic Engineering discipline with distinct control model and human role.

Brief Summary: Formalizes distinction between traditional deterministic software (code carries pre-written decision logic) vs agentic software (agent itself is software, decision logic generated at runtime); traces SaaS → Agent-as-a-Service shift; introduces Agentic Engineering discipline with distinct control model and human role.

Key Result: Demonstrates agentic paradigm transformative potential and current limitations via SWE-bench Verified, EvoClaw, LangChain multi-agent coordination studies; provides roadmap toward self-evolving agent ecosystems.
