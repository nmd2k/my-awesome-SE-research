Title: Mining Workflow Graphs for Black-Box Boundary Testing of Conversational LLM Agents

TL;DR: Black-box boundary testing via conversational workflow graph mining; discovers 23-38 distinct stateful boundaries per agent; structural guidance 23 vs 12 trivial baseline

Brief Summary: Black-box testing framework that mines conversational workflow graphs from agent interactions, then uses graph structure to enumerate stateful boundaries and test guards/prerequisites; applied to τ³-bench agents.

Key Result: Discovers 23-38 distinct boundaries per agent vs 12 for prompt-only baseline; structural guidance drives discovery; covers identity checks, confirmation gates, transaction endpoints.
