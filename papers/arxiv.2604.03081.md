Title: Supply-Chain Poisoning Attacks Against LLM Coding Agent Skill Ecosystems

TL;DR: DDIPE bypasses agent defenses 11–34% by embedding payloads in skill documentation

Brief Summary: Document-Driven Implicit Payload Execution (DDIPE): embeds malicious logic in skill documentation examples; agents execute payload via normal reuse without explicit prompt injection.

Key Result: 11.6–33.5% bypass rate across 4 frameworks; explicit attacks get 0% under strong defenses. 4 CVEs disclosed.
