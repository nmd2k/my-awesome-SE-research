Title: AgentGuard: An Attribute-Based Access Control Framework for Tool-Use LLM-Based Agent

TL;DR: Attribute-based access-control framework for tool-use LLM agents with lightweight client integration, server-side single-tool/cross-tool inspections, visual policy specification, and runtime auditing.

Brief Summary: Attribute-based access-control framework for tool-use LLM agents with lightweight client integration, server-side single-tool/cross-tool inspections, visual policy specification, and runtime auditing.

Key Result: Claims around 10 lines of client-side integration without changing agent execution logic; open-source prototype available.
