Title: From Exploration to Specification: LLM-Based Property Generation for Mobile App Testing

TL;DR: Automated LLM property generation for Android apps; enables property-based testing without manual spec writing

Brief Summary: PropGen automates property generation for Android app property-based testing using LLMs; explores app behavior, extracts functional properties (preconditions + postconditions), addresses the key bottleneck that manually writing properties is expensive and limits PBT adoption.

Key Result: Automated property generation for mobile apps, enabling scalable PBT without manual oracle specification.
