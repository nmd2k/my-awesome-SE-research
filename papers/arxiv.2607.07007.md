Title: Thinking More, Harnessing Better: State Machine Guided Harness Automatic Generation with Project Digestion and Workflow Decomposition

TL;DR: LLM-powered framework for automatic harness generation with dataflow aggregation and workflow decomposition: hybrid static analysis + LLM reasoning digests project, constructs minimal function groups; multi-stage generation with staged rollback self-corrects via targeted rollback to isolate hallucinations.

Brief Summary: LLM-powered framework for automatic harness generation with dataflow aggregation and workflow decomposition: hybrid static analysis + LLM reasoning digests project, constructs minimal function groups; multi-stage generation with staged rollback self-corrects via targeted rollback to isolate hallucinations.

Key Result: 3.07× higher branch coverage vs OSS-Fuzz-Gen, 1.71× vs CKGFuzzer, 4.26× vs PromeFuzz; 1.77-1.51× higher crash discovery on extensively fuzzed projects; discovered 7 previously unreported bugs (4 assigned CVEs).
