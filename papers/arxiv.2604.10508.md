Title: How Many Tries Does It Take? Iterative Self-Repair in LLM Code Generation Across Model Scales and Benchmarks

TL;DR: Systematic study of iterative self-repair (feeding execution errors back) for LLM code generation across 7 models (Llama 3.1/3.3/4, Qwen3-32B, Gemini 2.5 Flash/Pro) on HumanEval and MBPP Sanitized with up to 5 attempts.

Brief Summary: Systematic study of iterative self-repair (feeding execution errors back) for LLM code generation across 7 models (Llama 3.1/3.3/4, Qwen3-32B, Gemini 2.5 Flash/Pro) on HumanEval and MBPP Sanitized with up to 5 attempts.

Key Result: Self-repair universally improves pass rates: +4.9–17.1 pp on HumanEval, +16.0–30.0 pp on MBPP; most gains in first 2 rounds; assertion/logical errors hardest to fix (~45% repair rate).
