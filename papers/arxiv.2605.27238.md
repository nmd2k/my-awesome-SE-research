Title: EviACT: An Evidence-to-Action Framework for Agentic Program Repair

TL;DR: Evidence-to-action APR coordinates retrieval, compile, and test gates; +1.6-6.0 pp resolve rate with 70.1-88.6% lower reported per-bug API cost

Brief Summary: Agentic APR framework that coordinates three evidence-driven guardrails: retrieval-scaffold localization, compile-gate edit filtering, and target-test recovery before regression.

Key Result: Improves resolve rate over strongest comparable baselines by 1.6-6.0 pp across 4 benchmarks, with 70.1-88.6% lower reported per-bug API cost where available.
