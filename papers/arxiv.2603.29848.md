Title: AgentFixer: From Failure Detection to Fix Recommendations in LLM Agentic Systems

TL;DR: 15-tool validation framework diagnoses & fixes LLM agent failures; parsing = 38% of crashes

Brief Summary: Comprehensive validation framework with 15 failure-detection tools + 2 root-cause analysis modules; applied to IBM CUGA on AppWorld & WebArena benchmarks.

Key Result: Parsing issues = 38% of all production task failures; mid-size models (Llama 4, Mistral Medium) close frontier gap after fixes.
