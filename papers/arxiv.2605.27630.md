Title: OptiLoop: Coordination-in-the-Loop Verification and Repair for LLM-Generated Optimization Agents

TL;DR: Coordination-in-the-loop verification and repair for LLM-generated optimization agents, using bounded ADMM-style runs to expose semantic failures missed by local checks.

Brief Summary: Coordination-in-the-loop verification and repair for LLM-generated optimization agents, using bounded ADMM-style runs to expose semantic failures missed by local checks.

Key Result: On 40 held-out scenarios, improves objective match 66.0% -> 93.0% and social match 68.5% -> 89.0%, reducing objective gap 15.3% -> 3.5%.
