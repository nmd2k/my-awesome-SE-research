Title: Do LLMs Favor Their Providers? Measuring Vertical Integration Bias in Code Generation

TL;DR: Measures vertical-integration bias in code gen: affiliated models favor provider ecosystems up to +18.8 pp directly and +39.2 pp in agentic workflows

Brief Summary: Introduces VIBench for vertical-integration bias in direct and agentic code generation across 20 provider-selectable software-integration scenarios.

Key Result: Six of ten affiliated frontier models show significant direct bias up to +18.8 pp; agentic workflows amplify bias to +39.2 pp and persist early ecosystem choices up to 90.3%.
