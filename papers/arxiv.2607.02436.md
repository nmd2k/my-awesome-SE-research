Title: Reasoning effort, not tool access, buys first-try reliability in agentic code generation: an observational study

TL;DR: Observational study of 90 agent runs: xHigh reasoning effort lifts first-try perfect runs from 28% to 89% and cuts corrective prompts 5-fold; testing tools raise cost 42-68% without improving functional score or reliability

Brief Summary: Observational study of 90 agent runs: systematically varies model, harness, reasoning effort (High vs xHigh), testing tools, and design prompts on a real-time retrospective board task with fixed 14-criterion rubric.

Key Result: xHigh reasoning effort: first-try perfect 28% → 89%, corrective prompts 5-fold reduction; testing tool adds 42-68% cost with no functional/reliability gain; design prompt lifts visual quality 3.0 → 4.5-4.7 without functional improvement.
