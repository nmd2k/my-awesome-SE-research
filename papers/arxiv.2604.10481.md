Title: PatchRecall: Patch-Driven Retrieval for Automated Program Repair

TL;DR: Hybrid codebase + history-based retrieval improves file localization in APR

Brief Summary: Hybrid retrieval approach for APR file localization: combines codebase-level retrieval (semantic similarity) with history-based retrieval (similar historical patches) to balance recall and conciseness.

Key Result: Addresses the critical file-localization bottleneck in repo-scale automated program repair.
