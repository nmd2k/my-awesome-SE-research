Title: Beyond Human-Readable: Rethinking Software Engineering Conventions for the Agentic Development Era

TL;DR: Semantic density principle: redesign code conventions for LLM agents, not human readers

Brief Summary: Systematic analysis of human-centric SE conventions under agentic pressure; proposes semantic density optimization, program skeleton concept for navigation, and rehabilitation of classical anti-patterns.

Key Result: First framework for redesigning code conventions targeting LLM-agent consumers.
