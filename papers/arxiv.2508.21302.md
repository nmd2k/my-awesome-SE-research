Title: Locus: Agentic Predicate Synthesis for Directed Fuzzing

TL;DR: Agentic predicate synthesis for directed fuzzing: LLM synthesizes semantic predicates (constraints on program state) targeting specific vulnerabilities; uses SVF reachability analysis, KLEE symbolic execution for semantic validation; extends to various targets (vulnerability reports, patches, static analysis results).

Brief Summary: Agentic predicate synthesis for directed fuzzing: LLM synthesizes semantic predicates (constraints on program state) targeting specific vulnerabilities; uses SVF reachability analysis, KLEE symbolic execution for semantic validation; extends to various targets (vulnerability reports, patches, static analysis results).

Key Result: Demonstrates improved bug discovery vs baselines; enables fuzzing to target specific program states and conditions for effective vulnerability exploration.
