Title: Think Anywhere in Code Generation

TL;DR: Adaptive reasoning mechanism enabling LLMs to invoke thinking at any token position during code generation; RL learns when/where to reason; SOTA on LeetCode, LiveCodeBench, HumanEval, MBPP with consistent cross-model generalization

Brief Summary: Adaptive reasoning mechanism enabling LLMs to invoke "thinking" at any token position during code generation; cold-start training imitate reasoning patterns; RL rewards drive autonomous exploration of when/where to reason; adaptively allocates reasoning effort to high-entropy positions.

Key Result: SOTA on LeetCode, LiveCodeBench, HumanEval, MBPP; consistent generalization across diverse LLM families and model sizes; interpretability through reasoning entropy analysis.
