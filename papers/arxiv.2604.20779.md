Title: SWE-chat: Coding Agent Interactions From Real Users in the Wild

TL;DR: 6K real-user coding agent sessions: 41% vibe-coding, only 44% agent code survives to commit, agent code has more security bugs

Brief Summary: First large-scale dataset of real coding-agent sessions from open-source developers in the wild: 6,000 sessions, 63K+ user prompts, 355K+ agent tool calls; living dataset growing continuously. Analyzes adoption patterns, code quality, and human-agent dynamics in production.

Key Result: 41% "vibe coding" (agent authors all committed code); only 44% of agent code survives to commit; agent-written code introduces more security vulnerabilities than human code; users push back in 44% of turns.
