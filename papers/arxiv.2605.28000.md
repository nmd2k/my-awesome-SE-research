Title: Tool Forge: A Validation-Carrying Toolchain for Governed Agentic Execution

TL;DR: Validation-carrying toolchain that turns natural-language capability intent into governed, sandbox-verified, cataloged tool capsules with routing metadata and MCP-facing sessions.

Brief Summary: Validation-carrying toolchain that turns natural-language capability intent into governed, sandbox-verified, cataloged tool capsules with routing metadata and MCP-facing sessions.

Key Result: Router reaches 0.901 micro-F1 over 83 cases while reducing estimated tool context by 99.2%; 23/25 generated tool bundles pass live sandbox validation.
