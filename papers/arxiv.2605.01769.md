Title: VulKey: Automated Vulnerability Repair Guided by Domain-Specific Repair Patterns

TL;DR: Automated vulnerability repair guided by domain-specific repair patterns: two-stage pipeline with expert knowledge matching predicts repair pattern + pattern-guided fine-tuned LLM generates patches; explicitly models hierarchical expert knowledge (CWE types, syntactic actions, semantic elements).

Brief Summary: Automated vulnerability repair guided by domain-specific repair patterns: two-stage pipeline with expert knowledge matching predicts repair pattern + pattern-guided fine-tuned LLM generates patches; explicitly models hierarchical expert knowledge (CWE types, syntactic actions, semantic elements).

Key Result: 31.5% repair accuracy on PrimeVul (7.6% above best baseline); outperforms VulMaster (3.6×) and GPT-5 (3×); demonstrates cross-language and cross-model generalizability with SOTA on Java benchmark Vul4J (18 repairs vs 9 and 4 for baselines).
