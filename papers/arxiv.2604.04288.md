Title: LLM-Enabled Open-Source Systems in the Wild: An Empirical Study of Vulnerabilities in GitHub Security Advisories

TL;DR: Empirical analysis of 295 GitHub Security Advisories (Jan 2025–Jan 2026) referencing LLM components; manual annotation of 100 advisories using OWASP Top 10 for LLM 2025.

Brief Summary: Empirical analysis of 295 GitHub Security Advisories (Jan 2025–Jan 2026) referencing LLM components; manual annotation of 100 advisories using OWASP Top 10 for LLM 2025.

Key Result: Top risk patterns: Supply Chain, Excessive Agency, Prompt Injection; maps to established CWEs.
