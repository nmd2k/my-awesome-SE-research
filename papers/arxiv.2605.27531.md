Title: Agentic Separation Logic Specification Synthesis

TL;DR: Agentic separation-logic spec synthesis for million-LOC C++ codebases; 85% valid specs, no FPs under fuzzing/expert validation, 10x lower token cost than Claude Code Opus 4.6

Brief Summary: Neuro-symbolic-style specification synthesis combining LLM candidates with static analysis, heap tracing, fuzzing, and counterexample-guided validation for C++ functions.

Key Result: 85% valid specs, no observed false positives under fuzzing/expert validation.
