Title: VibeGuard: A Security Gate Framework for AI-Generated Code

TL;DR: Pre-publish security gate for vibe-coded projects; 100% recall on 8 real/synthetic projects

Brief Summary: Pre-publish security gate for vibe-coded projects; catches artifact hygiene, packaging drift, source-map exposure, hardcoded secrets, and supply-chain risks before npm publish.

Key Result: 100% recall, 89.47% precision (F1=94.44%) on 8 synthetic projects at 3 policy levels.
