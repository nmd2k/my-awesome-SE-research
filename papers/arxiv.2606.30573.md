Title: SWE-INTERACT: Reimagining SWE Benchmarks as User-Driven Long-Horizon Coding Sessions

TL;DR: Multi-turn, user-driven SWE benchmark where agents iteratively interact with a user simulator providing progressive requirement revelation, workspace inspection, and targeted feedback until task completion.

Brief Summary: Multi-turn, user-driven SWE benchmark where agents iteratively interact with a user simulator providing progressive requirement revelation, workspace inspection, and targeted feedback until task completion.

Key Result: Best models solve roughly 50% of single-turn baseline tasks but only 25% of interactive SWE-Interact tasks; strongest models (Opus 4.8, GPT-5.5) persevere better but still suffer from over-agentic coding and requirement forgetting.
