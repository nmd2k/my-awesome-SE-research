Title: Agentic Code Optimization via Compiler-LLM Cooperation

TL;DR: Multi-agent compiler-LLM cooperation for code optimization; up to 1.25× speedup over compiler-only

Brief Summary: Multi-agent system for code optimization via compiler-LLM cooperation: LLM agents at each abstraction level interleaved with compiler constituents, plus a test-gen agent and orchestrating LLM.

Key Result: Outperforms both standalone compilers and LLM-only baselines; up to 1.25× speedup.
