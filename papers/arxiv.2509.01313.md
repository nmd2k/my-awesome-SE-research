Title: Aligning Requirement for Large Language Model's Code Generation

TL;DR: ICSE 2026: specification alignment for LLM code gen; +29.60% Pass@1 vs. baselines

Brief Summary: Specification Alignment technique for LLM code gen (ICSE 2026): dual-agent (coder + tester) identifies misaligned specs, lifts LLM perception, aligns with original input specification.

Key Result: +29.60% avg Pass@1 over all baselines; 65.33% Pass@1 on APPS with Gemini-1.5-Flash.
