Title: Learning Reasoning World Models for Parallel Code

TL;DR: Reasoning LLMs predict race outcomes & performance profiles for parallel code; 7B model improves race-fixing 2.7–9.1% over self-feedback

Brief Summary: Reasoning LLMs trained to predict tool outcomes (data races, perf profiles) directly from parallel source code, bypassing expensive tool calls. A novel exploration pipeline generates hindsight reasoning traces causally linking code to observed tool behavior.

Key Result: 7B model improves from 64.3%→72.8% race-outcome prediction accuracy; world-model feedback improves race-fixing 2.7–9.1% over self-feedback (7B) and 6.1–11.1% (14B).
