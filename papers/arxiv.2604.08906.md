Title: Understanding Bugs in Modern Agentic Frameworks: A Study of Symptoms, Root Causes, and Triggering Conditions

TL;DR: Empirical study of 409 bugs in 5 agentic frameworks; cognitive context mismanagement = key root cause

Brief Summary: Systematic empirical study of 409 fixed bugs from 5 modern agentic frameworks (CrewAI, AutoGen, etc.); proposes a 5-layer abstraction and taxonomies for symptoms, root causes, components.

Key Result: Unique agentic symptoms: unexpected execution sequences, ignored user configs; root causes include cognitive context mismanagement and model backend faults.
