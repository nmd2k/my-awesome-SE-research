Title: Triage: Routing Software Engineering Tasks to Cost-Effective LLM Tiers via Code Quality Signals

TL;DR: Cost-aware SE task routing to LLM tiers via code health signals on SWE-bench Lite

Brief Summary: Cost-aware routing of SE tasks across LLM tiers (light/standard/heavy) using code health signals; evaluated on SWE-bench Lite (300 tasks, 3 tiers).

Key Result: Routes routine tasks to cheaper models; ML classifier closely tracks oracle-level savings.
