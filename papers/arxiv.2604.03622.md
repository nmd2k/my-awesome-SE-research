Title: Toward Executable Repository-Level Code Generation via Environment Alignment

TL;DR: Executable repo-level code gen via joint modeling of dependency + internal reference resolution

Brief Summary: Executable repository-level code generation framework that jointly models external dependency satisfaction and repository-internal reference resolution as an environment alignment problem.

Key Result: First to formulate repo executability as a constraint satisfaction problem; evaluated on RAL-Bench.
