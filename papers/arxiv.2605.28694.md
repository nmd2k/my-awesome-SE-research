Title: E-Path: Equality Saturation for Control-Flow Graphs

TL;DR: Prototype equality-saturation data structure for control-flow graphs, recording equivalence between instruction sequences embedded in compiler IR rather than expression trees.

Brief Summary: Prototype equality-saturation data structure for control-flow graphs, recording equivalence between instruction sequences embedded in compiler IR rather than expression trees.

Key Result: Enables non-destructive loop and CFG optimization variants without normalizing programs into structured/tree forms.
