Title: Strategic Heterogeneous Multi-Agent Architecture for Cost-Effective Code Vulnerability Detection

TL;DR: "3+1" heterogeneous agent architecture (3 expert LLMs + local verifier) for cost-effective vuln detection; AAMAS 2026

Brief Summary: "3+1" architecture: 3 cloud-based expert LLM agents (DeepSeek-V3) analyze code from complementary perspectives (structure, security patterns, debug traces) + 1 local lightweight verifier; game-theoretic budget allocation; balances detection accuracy with computational cost.

Key Result: Cost-effective vulnerability detection competitive with full-LLM baselines at fraction of cost.
