Title: False Security Confidence in Benign LLM Code Generation

TL;DR: FSC metric: measures vulnerable-but-correct LLM code; static analyzers miss FSC-hard vulnerabilities that remain dynamically triggerable

Brief Summary: Introduces FSC metric: prevalence of security failures within functionally correct LLM-generated code in ordinary (non-attack) tasks; formalizes "FSC-hard" subset where static analyzers miss vulnerabilities that remain dynamically triggerable; framework paper establishing terminology and measurement protocol.

Key Result: Reveals that conventional functional correctness evaluation does not capture security failures in correct code; creates benchmark (github.com/SysSoftwareSecLab/fsc-benchmark).
