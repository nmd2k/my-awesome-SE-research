Title: An Iterative Test-and-Repair Framework for Competitive Code Generation

TL;DR: Joint coder+tester training with iterative test-and-repair for competitive programming

Brief Summary: Iterative test-and-repair framework for competitive code generation: jointly trains Coder and Tester within a single model; inference-time Tester generates tests from problem description to filter Coder candidates.

Key Result: Treats competitive programming repair as continuous targeted test-and-repair; surpasses LLM-only baselines.
