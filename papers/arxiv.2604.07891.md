Title: AFGNN: API Misuse Detection using Graph Neural Networks and Clustering

TL;DR: MSR 2026: API Flow Graph + self-supervised GNN clustering for API misuse detection

Brief Summary: API Misuse Detection using Graph Neural Networks and Clustering (MSR 2026): novel API Flow Graph (AFG) captures API execution sequence, data/control flow; self-supervised GNN pre-training; cluster-based misuse detection (small clusters = misuse).

Key Result: Significantly outperforms SOTA small LMs and API misuse detectors at a fraction of model size.
