Title: Code as a Weapon: A Consensus-Labeled Prompt Bank for Measuring Coding-Model Compliance with Malicious-Code Requests

TL;DR: Consensus-labeled malicious-code prompt bank: 6,675 prompts, five-judge protocol, Fleiss' kappa 0.767; separates executable code requests from harmful knowledge

Brief Summary: Consensus-labeled malicious-code prompt bank consolidating 8 corpora and separating executable malicious code requests from harmful security knowledge requests.

Key Result: 6,675 prompts classified by 5 judges; Fleiss' kappa 0.767, 95.0% with at least 4 agreeing judges; releases 4,748 CODE and 1,923 KNOWLEDGE prompts.
