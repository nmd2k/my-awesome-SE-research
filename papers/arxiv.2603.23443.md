Title: Evaluating LLM-Based Test Generation Under Software Evolution

TL;DR: Large-scale (8 LLMs × 22,374 variants) mutation-driven study of LLM test generation sensitivity, resilience, and stability under semantic vs structural code change.

Brief Summary: Large-scale (8 LLMs × 22,374 variants) mutation-driven study of LLM test generation sensitivity, resilience, and stability under semantic vs structural code change.

Key Result: LLM-generated tests often miss semantic changes and over-fit to structural patterns.
