Title: CodeTracer: Towards Traceable Agent States

TL;DR: Traceable agent states: parses run artifacts → hierarchical trace tree → failure onset localization with replay recovery

Brief Summary: Tracing architecture for debugging code agents: parses heterogeneous run artifacts via evolving extractors → hierarchical trace tree with persistent memory → failure onset localization (earliest failure + downstream chain). Introduces CodeTraceBench from 4 agent frameworks on diverse code tasks.

Key Result: Substantially outperforms direct prompting and lightweight baselines; replaying diagnostic signals consistently recovers originally failed runs under matched budgets.
