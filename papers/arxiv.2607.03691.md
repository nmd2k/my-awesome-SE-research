Title: Don't Blame the Large Language Model: How Agent Harness Evolution Shapes Coding Agent Quality

TL;DR: Longitudinal study of 35 Qwen Code CLI releases: no statistically significant improvement in resolve rates despite hyper-churn (1.5-18 releases/week); later versions consume 2× tokens/tool calls without quality gains

Brief Summary: Longitudinal study of 35 sequential releases of Qwen Code CLI on 50 stratified SWE-bench Verified tasks with fixed underlying LLM; establishes "hyper-churn" patterns (1.5-18 releases/week, 2.8-34 commits/day) and development correlates.

Key Result: No statistically significant improvement in resolve rates across releases; later versions consume 2× tokens and tool calls; feature-heavy releases correlate with higher resolve (+0.438) but increased cost; fix-heavy releases increase cost without gains.
