Title: RAVEN: Retrieval-Augmented Vulnerability Exploration Network for Memory Corruption Analysis in User Code and Binary Programs

TL;DR: 4-agent RAG pipeline (Explorer→RAG→Analyst→Reporter) for memory corruption analysis in source & binary programs

Brief Summary: 4-agent RAG pipeline for memory corruption vulnerability analysis in user code and binary programs: Explorer agent identifies vulnerabilities → RAG engine retrieves curated knowledge → Analyst assesses impact and exploitation → Reporter generates structured root-cause analysis reports (Google Project Zero template).

Key Result: End-to-end automated synthesis of professional-grade vulnerability analysis reports for memory safety bugs.
