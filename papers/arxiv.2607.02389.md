Title: Steerability via constraints: a substrate for scalable oversight of coding agents

TL;DR: Proposes steerability-via-constraints principle: apply decades-old team management patterns (access control, network policies, coding conventions enforced by tooling) to coding agents; shows substrate-level oversight gains are largest in languages lacking default guarantees.

Brief Summary: Proposes steerability-via-constraints principle: apply decades-old team management patterns (access control, network policies, coding conventions enforced by tooling) to coding agents; shows substrate-level oversight gains are largest in languages lacking default guarantees.

Key Result: Backdoor detection: recall 54.5% (unconstrained) → 90.9% (constrained+tools); precision 100% maintained; 11 inserted backdoors across 5 sophistication levels.
