Title: PyFlow: An Inter-procedural Static Analysis Framework for Python

TL;DR: IFDS-based interprocedural dataflow framework for Python; achieves highest recall (48.1%) and F1-score (57.5%) on real-world benchmark vs 8 existing tools (CodeQL, Pysa, Semgrep, Snyk, etc.)
