Title: SNARE: Adaptive Scenario Synthesis for Eliciting Overeager Behavior in Coding Agents

TL;DR: Adaptive benign-scenario synthesis finds 19.51% overeager behavior across 10K coding-agent runs; framework explains more variance than base model

Brief Summary: Adaptive pipeline synthesizes benign coding-agent scenarios with scope traps and judge-free oracles to elicit out-of-scope actions that still complete the task.

Key Result: Over 10,000 benign runs across 4 agents x 5 models, 19.51% trigger overeager behavior; framework explains 56% of variance vs. 21% for base model.
