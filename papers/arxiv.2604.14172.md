Title: Tug-of-War within A Decade: Conflict Resolution in Vulnerability Analysis via Teacher-Guided Retrieval-Augmented Generations

TL;DR: Teacher-guided RAG resolves LLM knowledge conflicts in CVE analysis across 30K+ updated vulnerabilities

Brief Summary: Two-stage CRVA-TGRAG framework addressing LLM knowledge conflicts in CVE analysis: 30K+ CVEs have been updated/changed over the last decade causing training data staleness, factual fabrication, and hallucination; teacher-guided RAG retrieves latest CVE knowledge and resolves conflicts between internal LLM knowledge and external retrieved context.

Key Result: Reduces hallucination and factual conflicts in LLM-based CVE detection and analysis; maintains fresh knowledge without full retraining.
