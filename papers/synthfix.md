Title: SYNTHFIX: Adaptive Neuro-Symbolic Vulnerability Repair

TL;DR: Hybrid neuro-symbolic framework for vulnerability repair: adaptive training strategy where neural Router Model directs code samples to either Supervised Fine-Tuning (SFT) or Reward Fine-Tuning (RFT) with compiler-informed symbolic feedback; mirrors human developers alternating between pattern application and tool feedback.

Brief Summary: Hybrid neuro-symbolic framework for vulnerability repair: adaptive training strategy where neural Router Model directs code samples to either Supervised Fine-Tuning (SFT) or Reward Fine-Tuning (RFT) with compiler-informed symbolic feedback; mirrors human developers alternating between pattern application and tool feedback.

Key Result: 18% relative improvement Code BLEU/CrystalBLEU and 32% in Exact Match over strong SFT/RFT baselines on FixJS and Code Flaws; demonstrates adaptive combination significantly improves accuracy and efficiency of LLM-based vulnerability repair.
