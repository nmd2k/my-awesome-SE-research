Title: Harness Handbook: Making Evolving Agent Harnesses Readable,Navigable, and Editable

TL;DR: Behavior-centric harness representation linking runtime behavior to distributed source code via static analysis + LLM-assisted structuring; improves behavior localization and edit-plan quality for harness evolution with fewer planner tokens

Brief Summary: Behavior-centric harness representation linking runtime behavior to distributed source code via static analysis + LLM-assisted behavioral structuring; addresses behavior localization bottleneck in agent harness evolution by organizing knowledge by what harness does vs implementation details.

Key Result: Improves behavior localization, edit-plan quality, and reduces planner tokens on realistic agent harness modification tasks; automatic construction from source and LLM assistance enables practical adoption.
