Title: RAVEN: Agentic RAG for Automated Vulnerability Repair

TL;DR: Scalable agentic RAG framework with Curator Agent for cross-file dependencies; open-source LLMs in local deployment; 83.13% repair success on 160 real-world CVEs across diverse types and programming languages with strong OOD generalization

Brief Summary: Scalable agentic RAG framework for automated vulnerability repair combining retrieval + iterative repair with Curator Agent for cross-file dependencies; open-source LLMs in fully local deployment with limited GPU; multi-faceted retrieval pipeline retrieves historically relevant fixes and guides generation.

Key Result: 83.13% repair success on 160 real-world CVEs across diverse vulnerability types, 2 programming languages, unseen CWE categories, and OOD settings; outperforms all existing repair frameworks while maintaining negligible repair cost.
