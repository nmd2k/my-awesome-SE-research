Title: MIRAGE: Context-Aware Prompt Injection against Mobile GUI Agents via User-Generated Content

TL;DR: Context-aware prompt injection pipeline for mobile GUI agents that places attacker-controlled text into realistic user-generated-content regions of screenshots.

Brief Summary: Context-aware prompt injection pipeline for mobile GUI agents that places attacker-controlled text into realistic user-generated-content regions of screenshots.

Key Result: 1,111-sample benchmark over 10 apps and 11 attack intents finds all 5 evaluated VLM agents vulnerable at 23-30% ASR; realism is not correlated with attack success.
