Title: RealSWE: A Compositional Evaluation of Coding Agents under Realistic User Requests

TL;DR: Builds a data-grounded benchmark that varies how the same SWE task is described, showing that realistic user prompts materially reduce coding-agent performance.

Brief Summary: RealSWE derives an information taxonomy and linguistic-style dimensions from real SWE-chat prompts, then creates 381 task families whose underlying code task stays fixed while prompt composition changes. This isolates the impact of underspecification and writing style from raw task difficulty.

Key Result: Realistic inputs reduce resolution rates by 6.4 percentage points on average and can change model rankings. Desired behavior and feature motivation matter substantially, while reproduction steps and environment details often add tokens without measurable gains.
