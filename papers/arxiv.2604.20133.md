Title: EvoAgent: An Evolvable Agent Framework with Skill Learning and Multi-Agent Delegation

TL;DR: Evolvable LLM agent framework integrating structured skill learning with hierarchical sub-agent delegation; models skills as multi-file structured capability units with triggering mechanisms and evolutionary metadata; closed-loop user-feedback-driven skill generation and optimization; three-layer memory architecture for long-term capability accumulation.

Brief Summary: Evolvable LLM agent framework integrating structured skill learning with hierarchical sub-agent delegation; models skills as multi-file structured capability units with triggering mechanisms and evolutionary metadata; closed-loop user-feedback-driven skill generation and optimization; three-layer memory architecture for long-term capability accumulation.

Key Result: ~28% improvement across five LLM-as-Judge dimensions in real-world foreign trade scenarios with GPT-5.2.
