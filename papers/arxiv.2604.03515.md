Title: Inside the Scaffold: A Source-Code Taxonomy of Coding Agent Architectures

TL;DR: Source-code taxonomy of 13 coding agent scaffolds across 12 architectural dimensions

Brief Summary: Source-code-level architectural taxonomy of 13 open-source coding agent scaffolds, characterizing each across 12 dimensions in 3 layers: control architecture, tool/env interface, resource management.

Key Result: 5 loop primitives (ReAct, gen-test-repair, plan-execute, retry, MCTS) compose as building blocks; 11/13 agents mix multiple primitives.
