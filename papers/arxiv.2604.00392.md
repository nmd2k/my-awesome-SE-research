Title: Beyond Task Completion: A Verification-vs.-Conformance Gap in Tool-Evolving Agents

TL;DR: Benchmark treating LLM tool libraries as first-class SW artifacts; 18% quality gap at same task rate

Brief Summary: Benchmark that treats LLM-generated tool libraries as software artifacts, measuring reuse, redundancy, composition, regression, and safety (not just task completion).

Key Result: 18% library-health gap at similar 63–68% task completion; reveals invisible SW quality risks.
