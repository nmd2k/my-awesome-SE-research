Title: Dialogue SWE-Bench: A Benchmark for Dialogue-Driven Coding Agents

TL;DR: Multi-turn interactive coding agent benchmark: agents resolve SWE problems through natural language dialogue; schema-guided agent 46.9% resolve rate; strong coding ≠ dialogue ability (GPT-5 mini rivals GPT-5 at fraction of cost)
