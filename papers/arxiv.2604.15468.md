Title: The Semi-Executable Stack: Agentic Software Engineering and the Expanding Scope of SE

TL;DR: Position paper: SE's scope expands to semi-executable artifacts (natural language + tools + workflows + organizational routines) whose enactment is probabilistic, not deterministic; argues agentic SE will reshape software engineering around orchestration, verification, and trust.

Brief Summary: Position paper: SE's scope expands to semi-executable artifacts (natural language + tools + workflows + organizational routines) whose enactment is probabilistic, not deterministic; argues agentic SE will reshape software engineering around orchestration, verification, and trust.

Key Result: Conceptual framework for rethinking SE research and practice in the agentic era.
