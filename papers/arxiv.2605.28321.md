Title: Multi-Agent LLM-based Metamorphic Testing for REST APIs

TL;DR: Multi-agent LLM workflow for REST API metamorphic testing from OpenAPI docs; agents identify metamorphic scenarios, express them as Given-When-Then, implement, and execute tests.

Brief Summary: Multi-agent LLM workflow for REST API metamorphic testing from OpenAPI docs; agents identify metamorphic scenarios, express them as Given-When-Then, implement, and execute tests.

Key Result: On 2 public REST systems, ARMeta explores behaviors complementary to scenario-based testing baselines and targets the oracle problem in API testing.
