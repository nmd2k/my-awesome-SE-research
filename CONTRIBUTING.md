# Contibution guideline

To contribute to this list, please follow:

1. Take a critical look: is the proposed lib really awesome?
2. If does, add this lib in the relevant section at the last position. Bear in mind, that in many cases one library may fit multiple categories. Choose exactly one, to not duplicate contents.
3. Obviously, check if the library does not occur in the list!
4. Add a markdown note for that content inside `./papers/` that contains TL;DR, short description and link to the library. The format available at `./papers/_template.md`.
5. Adorn with coresponding icon(s) if possible
6. Feel free to propose any other changes in the list. New section? Removing an item? No problem, we'll think about it 😎
